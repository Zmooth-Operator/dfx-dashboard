# DFX Asset Dashboard

A live dashboard that displays all supported assets from the DFX Swiss public API.

## What it does

- Fetches all 179+ assets live from the DFX Swiss API
- Displays assets across 25+ blockchains
- Filter by blockchain
- Search by asset name
- No backend needed — runs entirely in the browser

## Tech stack

- TypeScript
- HTML & CSS
- DFX Swiss public API

## How to run

Clone the repository:
```bash
git clone https://github.com/Zmooth-Operator/dfx-dashboard.git
```

Open `index.html` directly in your browser — no server needed.

## About

Built to explore the DFX Swiss ecosystem. DFX is a Swiss crypto on/off-ramp supporting 80+ assets across 20+ blockchains.
